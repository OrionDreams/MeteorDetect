# MeteorDetect third-party license bundle

This directory is intended to be committed to the MeteorDetect repository and copied
verbatim into release packages.

Important: some dependencies in MeteorDetect are currently not pinned to exact versions.

FFmpeg build metadata is platform-specific. The GPLv3 license text is included at
ffmpeg/GPL-3.0.txt; each platform subdirectory explains details about that specific platform.
